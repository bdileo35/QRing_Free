# QRing Workspace

## Resumen del Proyecto

Este workspace es el punto de partida para el desarrollo de **QRing**, una aplicación móvil basada en Expo/React Native, con dos objetivos principales:

- **QRing Gratuito:** Una app simple para generar y escanear códigos QR, pensada para lanzar rápidamente en Play Store y ganar usuarios.
- **QRing PRO:** Una versión avanzada orientada a edificios y oficinas, con base de datos intermedia y una web tipo LandPage para administración, buscando rentabilidad y escalabilidad.

## Estrategia

1. **Empezar simple:** Usar solo lo esencial del proyecto básico de Expo y, si es útil, migrar partes de proyectos anteriores.
2. **Iterar rápido:** Lanzar primero la versión gratuita para validar la idea y obtener feedback.
3. **Escalar:** Desarrollar la versión PRO con backend y web de administración.
4. **Documentar todo:** Cada decisión, avance y aprendizaje se documentará aquí para no perder el hilo del trabajo.

## Primeros Pasos

- Crear el proyecto Expo básico en este workspace.
- Hacer el primer commit y subir el repo a GitHub/GitLab.
- Copiar/migrar solo lo necesario de proyectos anteriores.
- Anotar aquí cualquier decisión importante o cambio de rumbo.
